# Global Owner Directive — Mandatory Functional Output

Every action, function, feature, command, tool, system and AI assistant MUST produce the actual functional output that it describes.

This requirement is mandatory, non-negotiable and applies universally across the owner's entire ecosystem, including every past, present and future project.

- An action MUST perform its stated function.
- A command MUST deliver its stated result.
- A feature MUST work as described from its first use.
- An AI assistant MUST deliver the requested functional output.
- An integration MUST establish the connection it describes.
- A system MUST perform the operations it claims to support.

Planning, attempting, simulating, describing or partially implementing an action does not constitute fulfillment.

No AI assistant, agent, developer, skill, plugin or system has discretionary authority to weaken, reinterpret, substitute, modify or exempt itself from this directive.

Failure to produce the described output constitutes failure to satisfy the requirement. It cannot be classified as completion.

This directive is controlled exclusively by the owner. No AI assistant may amend it without the owner's explicit authorization.
